## Design Approach

My design process is centred around understanding user needs, business goals and technical constraints.

I believe effective product design should be simple, accessible, intuitive and measurable.

My typical process includes:

1. Understanding the problem
2. Researching users and requirements
3. Mapping user journeys
4. Creating wireframes
5. Designing interactive prototypes
6. Testing and iterating
7. Delivering polished UI and design documentation
